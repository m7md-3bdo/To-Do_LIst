# على القهوة النهارده

قايمة مهام (To-Do List) مبنية بـ HTML وCSS وJavaScript من غير أي مكتبة جافاسكريبت جاهزة للمنطق. الشكل متصمم على فكرة فاتورة القهوجي، وكوباية الشاي هي شريط التقدم: كل ما تخلص مهمة الشاي بيعلى، ولما تخلص كل المهام بيطلع البخار.

تم تنفيذه كميني بروجكت جماعي.

## المميزات

- إضافة مهمة جديدة بالـ Enter أو بزرار إضافة، مع رسالة تنبيه لو الخانة فاضية
- تقسيم المهام لـ 6 تصنيفات (شغل، مذاكرة، البيت، صحة، مشتريات، أفكار)، لكل تصنيف أيقونة ولون
- شطب المهمة بضغطة، والضغطة التانية بترجعها، وخط الشطب بيترسم بحركة
- تعديل نص المهمة مباشرة (Enter للحفظ، Esc للإلغاء)
- حذف المهمة من القايمة ومن الشاشة
- فلترة المهام حسب التصنيف، وعلى كل تاب عدد المهام المتبقية
- عداد المهام المتبقية (فاضل 3 مهام) ونسبة الإنجاز على شريط وكوباية الشاي
- تركيز بالشاي: مؤقت 25 دقيقة على مهمة معينة، وكل كوباية بتخلص بتتحسب في عداد النهارده
- اطلب من الجرسون: بيرشّحلك مهمة تبدأ بيها، خفيفة لو الوقت متأخر أو تعبت، ومحتاجة تركيز غير كده
- مستوى المجهود لكل مهمة (خفيفة / محتاجة تركيز)
- سلسلة الأيام: عداد بيزيد كل يوم بتشطب فيه مهمة ويتصفّر لو فات يوم
- مهام فرعية جوه كل مهمة بشريط تقدم صغير
- سحب وإفلات لترتيب المهام (على الكمبيوتر)
- الحساب: فاتورة بتلخص اللي خلصته النهارده، تنسخها أو تحفظها صورة
- إحصائيات آخر 7 أيام: المهام المنجزة والكوبايات وأكتر تصنيف
- رنة كوباية عند الشطب (بتتولّد بالكود ويتقفل من زرار الصوت)
- حفظ نسخة احتياطية JSON واستيرادها تاني
- تاريخ إضافة كل مهمة + ميعاد تسليم (تاريخ ووقت) بيتلوّن لما يقرب أو يفوت، وكارت بأقرب المواعيد
- تثبيت (Pin) للمهام المهمة عشان تفضل أول القايمة
- وضع نهاري دافي بيتحدد تلقائيًا حسب جهازك أو الوقت
- تراجع عن الحذف لمدة 5 ثواني
- وضع ليلي بيتحفظ في المتصفح
- حفظ الداتا في الـ LocalStorage، فالمهام بتفضل موجودة بعد قفل الصفحة
- شغال أوفلاين بالكامل: الخطوط والأيقونات محلية ومفيش أي رابط خارجي
- متجاوب مع الموبايل، ويحترم إعداد تقليل الحركة في النظام

## التقنيات

| الأداة | الاستخدام |
|---|---|
| HTML5 / CSS3 | الهيكل والتصميم |
| JavaScript (Vanilla) | المنطق والتعامل مع الـ DOM والـ Array والـ LocalStorage |
| Bootstrap 5.3 | الـ reboot وبعض الـ utility classes |
| Font Awesome 7 Free | الأيقونات |
| Aref Ruqaa / Marhey / Tajawal | الخطوط العربي |

## هيكل المشروع

```
todo-project/
├── index.html
├── Css/
│   ├── style.css          تصميم المشروع
│   ├── bootstrap.min.css
│   └── all.min.css        Font Awesome
├── js/
│   ├── main.js            منطق التطبيق الأساسي
│   ├── extras.js          خطوات فرعية، سحب وإفلات، حساب، أسبوع، صوت، نسخة احتياطية
│   ├── features.js        المميزات الإضافية (تركيز، جرسون، سلسلة، تراجع، وضع ليلي)
│   └── bootstrap.bundle.min.js
├── fonts/                 الخطوط العربي (محلية)
└── webfonts/              خطوط الأيقونات (محلية)
```

كل قسم في `main.js` عليه تعليق بيشرح بيعمل إيه، ومترتب كالتالي: الإعدادات، الداتا، الإضافة، الشطب، التعديل والحذف، العرض، الفلترة، العداد.

## تشغيل المشروع

مفيش تثبيت ولا سيرفر. نزّل الريبو وافتح `index.html` في أي متصفح.

```bash
git clone <رابط-الريبو>
cd todo-project
# افتح index.html
```

## إضافة تصنيف جديد

التصنيفات متعرّفة في مكان واحد في أول `js/main.js`. أضف سطر جديد في المصفوفة `CATEGORIES` وهيظهر في الاختيار وفي التابات لوحده:

```js
{ id: "travel", label: "سفر", icon: "fa-plane", color: "#3a7ca5" }
```
